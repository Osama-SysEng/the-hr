# The H.R - AI HR Operating System

منصة إدارة الموارد البشرية المتكاملة والأوتوماتيكية بالذكاء الاصطناعي.

## الموديولات
- Smart Attendance System (4-layer biometric)
- Payroll Engine (Egyptian tax & insurance)
- AI Recruitment (500+ CVs in 5 min)
- Supply Chain Management
- AI Analytics & Predictions
- Employee Self-Service Portal

## التقنية
- FastAPI + PostgreSQL + SQLAlchemy + Redis + Celery
- React 18 + TypeScript + Tailwind CSS
- JWT + RBAC
- OpenAI + Gemini AI
- OpenCV + face_recognition

## البدء
```bash
cd the-hr
docker-compose up -d
```
