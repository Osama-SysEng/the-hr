# تفعيل MY-CV في بيئة مؤسسية

| المرحلة | بوابة القبول |
|---|---|
| Staging | هوية HR، تخزين مشفر، فحص ملفات، واستخراج في worker معزول. |
| البيانات | سياسة احتفاظ وحذف، سجل وصول، تصنيف ملفات المرشحين، وقاعدة بيانات للوظائف والمعايير والقرارات البشرية. |
| النطاق | صف يدعم أكثر من 500 ملف، idempotency للرفع، ومراقبة queue ووقت الاستخراج ونسبة الأخطاء. |
| الأمن | مدير أسرار، فحص تبعيات، حماية من ملفات خبيثة، حد حجم/نوع، وواجهة تنزيل بصلاحية مؤقتة. |
| الإنتاج | اختبار حمل staging، نسخة احتياطية واستعادة، وتوقيع مالك المنتج والأمن والموارد البشرية. |

لا تحفظ ملفات السير أو نتائجها في سجلات التطبيق، ولا ترسلها إلى مزود نموذج خارجي دون عقد معالجة بيانات وموافقة الشركة والمرشحين حيث يلزم.
