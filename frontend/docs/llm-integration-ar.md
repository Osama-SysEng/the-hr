# دمج LLM لاستخراج مهارات السير الذاتية

تُشغّل الخدمة من الخادم فقط بعد رفع الملف واستخراج نصه في worker معزول. يرسل الخادم النص ومعايير الوظيفة إلى `llm-extraction.ts` ويطلب JSON صارمًا يضم المهارات والأدلة النصية والثقة والنقاط غير المحسومة. لا تمر مفاتيح النموذج أو نصوص السير إلى المتصفح.

| خطوة | الضابط |
|---|---|
| التحضير | اخفِ الاسم وبيانات الاتصال والسمات الحساسة إن لم تكن لازمة للمهمة، وحدد حدًا لحجم النص. |
| الاستدعاء | استخدم نموذجًا اقتصاديًا لاستخراج منظم، ثم schema validation وretry محدود. |
| النتيجة | اعرض الدليل والثقة والتحذير للمراجع، ولا تحول الناتج إلى قبول أو رفض آلي. |
| الجودة | أعد تحليل حالات الثقة المنخفضة فقط بموديل أقوى، وسجل model/version ومدة المعالجة دون حفظ النص الخام في logs. |
| الخصوصية | راجع عقد معالجة البيانات وموافقة الشركة والمرشحين وسياسة الاحتفاظ قبل إرسال أي CV لمزود نموذج. |

> يفصل MY-CV بين **استخراج حقائق مرتبطة بالوظيفة** و**قرار التوظيف البشري**. لا يسمح prompt أو المخطط بطلب توصية توظيف أو استنتاج سمات محمية.
