# Security

## المصادقة
- JWT tokens مع مصادقة قوية
- RBAC (Role-Based Access Control) مع 6 أدوار
- كلمات مرور bcrypt (12 rounds)
- TLS 1.3 للاتصالات

## البيانات
- AES-256 تشفير للبيانات الحساسة
- بيانات البصمة والوجه تخزن كمتجهات رياضية فقط (ليس صوراً)
- Multi-tenant isolation (شركة لا ترى بيانات شركة أخرى)
- حذف Automatic للبيانات القديمة

## المراجعة
- كل الإجراءات مسجلة في AuditLog
- IP 주소와 user agent مسجل
- 실패한 محاولات الدخول مسجلة و قد تؤدي إلى قفل الحساب

## الخصوصية
- CVs تخزن كنصوص فقط ولا تُرسل إلى LLMs خارجي إلا مع عقد معالجة
- المقابلات AI مسجلة مع موافقة
- البيانات محذوفة تلقائياً بعد 90 يوم (قابل للتغيير)
